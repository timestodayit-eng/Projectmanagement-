# RecruitOps Team Quick Guide / টিমের সহজ নির্দেশনা

**Super Admin:** তিন প্রতিষ্ঠানের সব কাজ দেখতে পারবেন। **Company Admin / Manager:** শুধু নিজের প্রতিষ্ঠানের টিমের কাজ Assign, Review এবং Approve করবেন। **Team Member:** নিজের প্রতিষ্ঠানের কাজ দেখবেন এবং Assign করা কাজ জমা দেবেন।

প্রতিদিন: **Overview → My Tasks → Team Requests → Interviews → Campaign Planner**।

- New Task: Name, Company, Team, Assignee, Due Date, Priority এবং Brief/Link দিন।
- Team Request: Requesting Team, Receiving Team, Requirement এবং Deadline দিন।
- In Progress: দায়িত্বপ্রাপ্ত কর্মী কাজ শুরু করেছেন।
- In Review: Deliverable / Drive Link জমা দিয়েছেন; Manager যাচাই করবেন।
- Completed: Manager Approved; ভুল হলে Revision Required।
- Interview Planner: প্রতিটি Interview-এর আলাদা Campaign Budget। Interview-এর ৭ দিন আগে Campaign launch।
- Budget: CALL ৫০%, WEB ৫০%। প্রত্যেক চ্যানেলের ৭০% Awareness, ১৫% Retargeting, ১৫% Conversion।
- Creative per Page: ৪ CALL + ৩ WEB। Coastal এবং SM per Page: ৩ CALL + ৩ WEB।
- কোনো এড সত্যিই Live কিনা Meta Ads Manager-এ পরীক্ষা করুন; শিট/অ্যাপের টিক একা প্রমাণ নয়।
- সোর্স ডেটা: Settings-এ Mother Google Sheet Link; Server Service Account প্রয়োজন।
